# Política de Privacidade — OpenSetList

Última atualização: 14 de agosto de 2026

## Resumo

O OpenSetList é um aplicativo de setlists e cifras para músicos. Ele foi projetado para funcionar **totalmente offline** e **não coleta nenhum dado pessoal**.

## Dados que coletamos

**Nenhum.** O OpenSetList não coleta, armazena em servidores, processa nem compartilha dados pessoais. Não há contas, cadastro, analytics, publicidade ou rastreamento.

## Onde seus dados ficam

Todo o seu conteúdo (músicas, setlists, artistas, tags, configurações) é armazenado **exclusivamente no seu aparelho**, em um banco de dados local do aplicativo.

## Permissões do dispositivo

O aplicativo solicita as seguintes permissões, usadas apenas para o funcionamento do recurso de pedal Bluetooth (opcional):

- **Bluetooth** (conexão com pedal de paginação, por exemplo): usada somente para conectar a um pedal Bluetooth escolhido por você.
- **Localização** (apenas em versões antigas do Android, até a API 30): exigida pelo sistema para a varredura de dispositivos Bluetooth próximos. O OpenSetList **não usa** a sua localização e não a coleta.

O aplicativo também permite selecionar arquivos (backups, setlists) pelo seletor de arquivos do sistema (incluindo Google Drive/Dropbox). Apenas os arquivos que você escolher são lidos.

## Compartilhamento de dados

O OpenSetList não compartilha dados com terceiros.

## Exclusão de dados

Para apagar todos os dados do aplicativo, desinstale-o ou limpe os dados do app nas configurações do sistema.

## Alterações nesta política

Esta política pode ser atualizada conforme necessário. Alterações serão publicadas nesta página.
